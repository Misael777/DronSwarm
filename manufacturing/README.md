# Paquete de fabricación

- `bom/` — listas de materiales.
- `costeo/` — costeo unitario y make-vs-buy.
- `procesos/` — procesos de fabricación.
- `manuales/` — manuales de fabricación y ensamble.
- `calidad/` — control de calidad y pruebas de aceptación (ATP).
- `planos/` — planos Rev A exportados de FreeCAD.
