# Documentación del proyecto

- `plan/` — plan de trabajo: Excel de seguimiento (usuario) y `PLAN_DE_TRABAJO.md` (agente).
- `guia-estructura-repo.md` — estructura del monorepo y convenciones para el agente.
- `decisiones.md` — registro de decisiones técnicas (ADR).
- `requisitos/` — PRD, historias de usuario, targets, trazabilidad.
- `negocio/` — costo objetivo, precios, presupuestos.
- `ingenieria/` — informes de diseño y de pruebas.
- `evidencias/` — resultados de simulación, vuelos y campo.
- `revisiones/` — actas de los Gates (G0-G7).
- `calidad/`, `operacion/` — FMEA, confiabilidad, manuales de operación.
- `referencias/` — fichas técnicas DJI y cotizaciones (benchmark).
- `flujo/` — PDF del flujo de trabajo (generado por `tools/docs/generar_flujo_drones_mineria.py`).
